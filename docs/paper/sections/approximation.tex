\section{Proposed Approximation}
\label{sec:approx}

\subsection{Derivation Strategy}

We seek an interpolation between $\Tub$ and $\Tbot$ that satisfies:
\begin{enumerate}
\item \textbf{Exactness:} Reduces to~\eqref{eq:nelson-tantawi} when $\mu_1 = \mu_2$.
\item \textbf{Light traffic} ($\lambda \to 0$): $T \to \Tub$ (nearly independent tasks).
\item \textbf{Heavy traffic} ($\rho \to 1$): $T \to \Tbot$ (bottleneck dominance).
\item \textbf{Bound compliance:} $\Tbot \leq T \leq \Tub$ for all valid parameters.
\end{enumerate}

\subsection{The Formula}

Define the average utilization $\bar{\rho} = (\rho_1 + \rho_2)/2$ and the interpolation weight:
\begin{equation}
\alpha = \frac{\bar{\rho}}{4} = \frac{\rho_1 + \rho_2}{8}.
\end{equation}
Then:
\begin{equation}
\label{eq:approx}
\boxed{T \;\approx\; (1 - \alpha)\, \Tub \;+\; \alpha\, \Tbot}
\end{equation}
where $\Tub$ and $\Tbot$ are given by~\eqref{eq:tub} and~\eqref{eq:tbot}.

Equivalently:
\begin{equation}
T \;\approx\; \left(1 - \frac{\rho_1 + \rho_2}{8}\right) \Tub \;+\; \frac{\rho_1 + \rho_2}{8}\; \Tbot.
\end{equation}

\subsection{Verification: Homogeneous Case}

When $\mu_1 = \mu_2 = \mu$, we have $\rho_1 = \rho_2 = \rho$, $\alpha = \rho/4$, and:
\begin{itemize}
\item $\Tub = 2T_1 - T_1/2 = \tfrac{3}{2}\, T_1$
\item $\Tbot = T_1$
\end{itemize}
Substituting into~\eqref{eq:approx}:
\begin{equation}
T = \left(1 - \frac{\rho}{4}\right)\frac{3}{2}\,T_1 + \frac{\rho}{4}\, T_1 = \frac{3}{2}\,T_1 - \frac{3\rho}{8}\,T_1 + \frac{\rho}{4}\,T_1 = \frac{12 - \rho}{8}\, T_1,
\end{equation}
which exactly recovers the Nelson--Tantawi result~\eqref{eq:nelson-tantawi}.
